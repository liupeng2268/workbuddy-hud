# v1.0.2

补齐 v1.0.1 发布说明里列为「已知限制」的四项，并修若干可用性缺口。v1.0.1 的 Release 与附件保持不变。

## 数据正确性

| 修复 | 修复前 | 修复后 |
|------|--------|--------|
| 文件被截断或重写后重复计数 | 旧数据被再算一遍，误差永久累积 | 按文件记录已贡献的明细，重读前先扣回；实测 10 条清空重写为 3 条，会话与历史都得 3（原为 13） |
| 运行期新增的大文件头部丢失 | 历史口径只回溯末尾 4 MB，前面的数据永不入账 | 历史口径的新文件一律从头读，靠既有预算分轮补完；实测 2000 条全部入账 |
| 停止生成后仍显示旧速率 | 速率只按样本之间的跨度计算，不看「现在」，停止后最长残留 60 秒 | 窗口锚到当前时刻，最新样本超过 15 秒未更新即置空并标记空闲 |
| 单条样本时速率闪 `--` | 要求窗口内至少 2 条样本，否则显示占位符 | 单条样本也给出数值 |

回归用例从 15 项扩到 30 项；真实日志对账 22,838 条记录，程序历史口径 22,838 条，差值 0。

## 可用性

- **单实例**：重复双击不再起第二个进程各扫一遍几百 MB 日志（Windows 互斥体，非 Windows 自动放行）。
- **窗口找得回来**：拖动时保证至少留 60×40 px 在屏幕内；位置写入 `设置.json`，下次启动沿用；位置失效才回落右下角。
- **保存失败有提示**：程序目录不可写时不再静默关窗，设置窗口底部显示原因，当次设置仍生效。
- **键盘路径**：设置窗口支持 Esc 取消、Enter 保存。
- **首次引导**：首次运行第三行临时显示「右键设置 · 按住拖动」，20 秒后恢复指标。
- **排障入口**：右键菜单新增「打开程序目录」；错误文案从 28 字符放宽到 40。

## 下载与校验

附件名为 `WorkBuddy-HUD.exe`（ASCII，避免中文文件名在部分下载工具里被截断）；程序自身名称仍是 `WorkBuddy悬浮窗.exe`。

```
SHA256  8E939A8E07CDE353F4BA898BE50110A53477CCC314E53A6AA1787E8955EF5674
```

PowerShell 校验：

```powershell
Get-FileHash .\WorkBuddy-HUD.exe -Algorithm SHA256
```

本版未做代码签名，首次运行若出现 SmartScreen 提示属预期。

## 已知限制

- 历史口径每 3.2 秒增量一次，数字比会话口径滞后一拍；这是两套口径各自维护读取位置的代价，不是缺陷。
- 文件被原地改写但大小未变小时仍无法识别，会重复计数；判别需要文件身份信息（见 [0002](../adr/0002-按文件明细记账.md)）。
- 未声明 DPI 感知，高缩放屏上文字可能被系统位图拉伸发虚。
- 主窗口无标题栏、不进任务栏，仍只能靠右键菜单退出。
